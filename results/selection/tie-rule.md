# Predeclared selection rule

Select among executed, valid harnesses by the largest fraction of required Ancha state/trace checks passed. Invalid trials cannot win. On a tie prefer composition (`agg1`), then baseline (`base1`). The code's stable order resolves any remaining tie between proposals; it defines no further semantic preference.

This rule was in the adapter before the candidate outcomes. Both recorded selections chose `agg1`. Selection happens after the core Propose–Probe–Compose executions; the editor and composer receive no numerical verdicts. A selection can preserve baseline performance, as the Sonnet episode did.
